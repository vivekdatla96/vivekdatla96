### 📌 Featured project

**[healthcare-claims-lakehouse](https://github.com/vivekdatla96/healthcare-claims-lakehouse)**
A medallion pipeline for healthcare claims: CDC with out-of-order protection, SCD Type 2 member
history, PHI tokenization, a data quality gate, dbt gold models with point-in-time joins, and an
Airflow DAG. Runs end to end on DuckDB, tested in CI.
